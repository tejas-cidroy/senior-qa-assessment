**Test basis:** WC-FDD-1.0-89d9, WC-RN-1.0-89d9, OpenAPI 3.1, live screens · **Assumptions:** see `01-questions-assumptions.md`
**Environment:** see test plan · **Store clock:** every time-based case states the clock it sets and resets it afterwards (R-01)

## Conventions

| Field | Meaning |
|---|---|
| ID | `TC-<area>-<nn>`; areas: AUTH, CAT, CART, CHK, ORD, CAN, SLOT, RED, REO, REF, INV, STM, INQ, SEL, CSV, PAR, OPS, ACC (access), NFR |
| Priority | P1 / P2 / P3 as defined in the test plan |
| Technique | BVA (boundary values), EP (equivalence partitions), ST (state transition), DT (decision table), NEG (negative), E2E |
| Level | UI / API / both |
| Expected | Cites the rule (BR / IF / NF / CR) and any assumption (Q-xx) it relies on |
| Auto | Automated test file and title, or blank |
| Result | Pass / Fail (DEF-xx) / Blocked / Not run |
